🔄 Data Flow Process

  1. User Request → Web/LINE interface sends request
  2. State Management → TanStack Query caches & fetches data
  3. API Route → Next.js Edge Function processes request
  4. Authentication → Supabase Auth verifies user + RBAC checks permissions
  5. Business Logic → AI processing (if needed) + data transformation
  6. Database → PostgreSQL with RLS policies enforces security
  7. Response → JSON data returns to client
  8. UI Update → React re-renders with new data
  9. LINE Push (optional) → Flex Message notification sent
