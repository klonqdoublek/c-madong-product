🎯 Key Insights from this Service Blueprint:

AI Vision Multi-Tier Approach: Template matching (free, <1s) handles 70% of cases → Gemini 2.0 Flash (free tier) for 25% → GPT-4o fallback (paid) only for 5% low-confidence cases = ~฿1/month for 50 tickets (93% cost savings).

Touchpoint Diversity: LINE chatbot (immediate), Web app (detailed), Admin portal (management) — students can choose their preferred channel.

Real-time Updates: Supabase subscriptions ensure students see status changes instantly without polling.

Pain Points Identified: Photo quality affects AI accuracy (opportunity: smart photo guidance with real-time tips "📸 ถ่ายใกล้ขึ้น").
