## 🎨 Design Notes

### Tone Consistency
- ใช้ **particles** นะ/จ้า/เลย แทน ครับ/ค่ะ (gender-neutral)
- **Verb-first** — แจ้งซ่อม, เช็คบิล, ดูคะแนน
- **Short sentences** — max 2 clauses
- **Active voice** — "น้องตอบไว" not "ถูกตอบอย่างรวดเร็ว"

### Visual Hierarchy
- **Hero**: ใหญ่ ชัด ตรงประเด็น
- **Features**: icon + short headline + 2-sentence description
- **LINE OA**: เน้น personality ของน้องซีมะโด่ง (friendly, helpful)
- **CTA**: ชัดเจน มองเห็นง่าย

### Emoji Usage
- ใช้พอประมาณ (1-2 per section)
- ไม่ใช้ในทุกประโยค (ดูเยอะเกินไป)
- เลือกที่เข้ากับ context: 🔧 แจ้งซ่อม, 📦 พัสดุ, 🤖 chatbot
