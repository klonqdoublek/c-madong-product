🔀 Key Data Flows
🔧 Repair Request Flow (LINE → Web → LINE)
Student (LINE) → Webhook → Intent Router → Repair Handler → Session State → Collect Info → Supabase INSERT → Flex Card ✅ → Admin Reviews → Status Update API → LINE Push + In-App Notif
📚 Knowledge Base RAG Flow
Admin Upload PDF → unpdf Parse → Chunk Text → OpenAI Embedding → pgvector Store → User Question → Vector Search (cosine) → GPT-4o-mini Answer
🔐 Authentication Flow
LINE Login → OAuth Code → /api/auth/callback → Exchange Token → Get LINE Profile → Supabase signUp (synthetic email) → Upsert Profile → Set Cookie → Dashboard
